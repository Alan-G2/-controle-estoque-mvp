# Sistema de Controle de Estoque

## Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema web para auxiliar no controle de estoque de uma empresa que realiza vendas em loja física e por meio da plataforma Nuvemshop.

A aplicação busca centralizar as informações dos produtos e das movimentações de estoque, facilitando o acompanhamento das entradas, saídas e vendas realizadas nos diferentes canais.

## Objetivo do MVP

Desenvolver uma versão inicial que permita:

- Cadastrar produtos.
- Registrar entradas e saídas de estoque.
- Registrar vendas realizadas na loja física.
- Integrar os pedidos da Nuvemshop.
- Atualizar as quantidades disponíveis no estoque.
- Consultar produtos com estoque baixo ou indisponível.

## Status do projeto

Em fase inicial de desenvolvimento.
